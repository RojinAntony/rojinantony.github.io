# Rojin Antony — Classic Portfolio

A responsive, professional portfolio website for GitHub Pages.

## Files
- `index.html` — portfolio content
- `styles.css` — classic light design and responsive layout
- `script.js` — mobile navigation and footer year
- `profile.jpg` — optional portrait image (add your own)

## Publish on GitHub Pages
1. Upload these files to the root of `rojinantony.github.io`.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the Pages deployment to finish.

## Before publishing
- Replace the LinkedIn placeholder URL with your actual profile URL.
- Add a portrait as `profile.jpg` if desired.
- Review technical skills and project descriptions for accuracy. The project cards are representative summaries, not claims of public repositories or independently verified results.
- Do not publish client names, credentials, private IP addresses, logs, or sensitive infrastructure diagrams.
